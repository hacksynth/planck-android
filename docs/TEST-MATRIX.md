# 真机测试矩阵

测试结果必须记录构建提交、内核提交、DTB 变体、BIOS 版本和 EC 版本。

## 启动

| 用例 | 通过标准 |
|---|---|
| UKI 冷启动 | 连续 5 次进入 Android，无 init/rescue party 循环 |
| UKI warm reboot | `reboot` 后仍能启动 |
| UEFI `F12` | USB ESP 可见，能识别 `BOOTAA64.EFI` |
| host DTB | 系统可启动，USB-C host 设备枚举 |
| debug DTB | USB `adb devices` 可见设备 |

## 显示与输入

| 用例 | 通过标准 |
|---|---|
| 内屏 | 2160x1440，无无头 HWC、无颜色错位 |
| 触摸 | 单点、多点、边缘、长按、拖拽 |
| 手写笔 | 独立 stylus 输入、压感和悬浮 |
| 磁吸键盘 | 按键与触摸板 |
| 亮度 | 滑块、亮灭屏、自动亮度 |
| 旋转 | 平板模式开关、加速度计自动旋转 |

## 电源与 USB-C

| 用例 | 通过标准 |
|---|---|
| 电池 | 容量、电压、电流、温度合理 |
| 充电器 | 插拔、充电状态、PD 角色稳定 |
| Lid | 合盖熄屏、开盖唤醒 |
| Suspend | 多次 s2idle，无重启或 EC 死锁 |
| USB host | U 盘、键盘、USB 网卡 |
| DisplayPort | USB-C 外接显示器与拔插恢复 |

## 无线

| 用例 | 通过标准 |
|---|---|
| Wi-Fi 扫描 | 2.4/5 GHz 热点可见 |
| Wi-Fi 连接 | WPA2/WPA3、DHCP、DNS、HTTPS |
| Wi-Fi 恢复 | 休眠唤醒、固件恢复、路由器重连 |
| 热点 | STA+AP 并发或明确降级 |
| 蓝牙 | 键鼠、耳机、BLE 扫描 |
| 蓝牙恢复 | 关闭/打开、休眠唤醒、长时间运行 |

## 媒体与相机

软件渲染首版不要求游戏性能，但必须记录实际结果：

- H.264/HEVC 软件或硬件解码。
- 录屏、视频编码。
- 扬声器、耳机、内置麦和耳机麦。
- 前摄、后摄、隐私灯、对焦和曝光。

任何未测项目保持“未验证”，不能按内核驱动已加载推断为可用。
